LOOPING 1 - MODUL 2: KOMPONEN VISUAL
============================================================

1. KONSEP CEPAT
- Form      : jendela/wadah utama aplikasi.
- Button    : tombol untuk menjalankan perintah.
- Label     : menampilkan teks atau keterangan.
- TextBox   : tempat pengguna mengetik atau mengedit teks.
- Event     : kejadian yang menjalankan kode, misalnya tombol diklik.
- .Text     : membaca atau mengubah teks pada kontrol.
- .Clear()  : mengosongkan TextBox.
- Me.Close(): menutup Form yang sedang aktif.
- MessageBox.Show(): menampilkan kotak pesan.
- &         : menggabungkan teks/nilai.
- vbCrLf    : membuat baris baru.

2. TEMPLATE: EVENT TOMBOL
------------------------------------------------------------
Private Sub BtnTampilkan_Click(sender As Object, e As EventArgs) Handles BtnTampilkan.Click

    ' Tulis kode yang dijalankan saat tombol diklik di sini.

End Sub
------------------------------------------------------------
Gunakan template ini untuk event klik tombol. Sesuaikan nama
BtnTampilkan dengan nama tombol pada Form.

Dim nama As String = TxtNama.Text

String berarti tipe data teks. Ganti nama kontrol sesuai Form.

5. MENAMPILKAN BEBERAPA INPUT DALAM SATU MESSAGEBOX
------------------------------------------------------------
Private Sub BtnTampilkan_Click(sender As Object, e As EventArgs) Handles BtnTampilkan.Click

    ' Menampilkan data dari tiga TextBox dalam beberapa baris.
    MessageBox.Show("Halo Selamat Datang!" & vbCrLf &
                    "Nama : " & TxtNama.Text & vbCrLf &
                    "NIM  : " & TxtNim.Text & vbCrLf &
                    "Kom  : " & TxtKom.Text)

End Sub
------------------------------------------------------------
Kunci:
- Teks di dalam tanda kutip adalah tulisan tetap.
- TxtNama.Text mengambil isi TextBox.
- & menggabungkan tulisan dan isi TextBox.
- vbCrLf membuat baris baru.

6. MENAMPILKAN INPUT KE LABEL
------------------------------------------------------------
Private Sub BtnTampilkan_Click(sender As Object, e As EventArgs) Handles BtnTampilkan.Click

    ' Menampilkan isi TxtNama ke Label.
    LblHasil.Text = "Halo, " & TxtNama.Text

End Sub
------------------------------------------------------------
LblHasil harus merupakan nama Label yang benar di Form.

7. MENGHAPUS ISI TEXTBOX
------------------------------------------------------------
Private Sub BtnHapus_Click(sender As Object, e As EventArgs) Handles BtnHapus.Click

    ' Mengosongkan isi TextBox.
    TxtNama.Clear()
    TxtNim.Clear()
    TxtKom.Clear()

End Sub
------------------------------------------------------------
Tambahkan satu baris .Clear() untuk setiap TextBox yang ingin
dikosongkan.

8. MENGOSONGKAN TEXTBOX DAN LABEL
------------------------------------------------------------
Private Sub BtnHapus_Click(sender As Object, e As EventArgs) Handles BtnHapus.Click

    TxtNama.Clear()
    TxtNim.Clear()
    TxtKom.Clear()

    ' Opsional: mengosongkan teks pada Label.
    LblHasil.Text = ""

End Sub
------------------------------------------------------------

9. MENUTUP FORM
------------------------------------------------------------
Private Sub BtnKeluar_Click(sender As Object, e As EventArgs) Handles BtnKeluar.Click

    ' Menutup Form yang sedang aktif.
    Me.Close()

End Sub
------------------------------------------------------------

10. EVENT TEXTCHANGED
------------------------------------------------------------
Private Sub TxtNama_TextChanged(sender As Object, e As EventArgs) Handles TxtNama.TextChanged

    ' Label mengikuti teks yang sedang diketik.
    LblHasil.Text = TxtNama.Text

End Sub
------------------------------------------------------------
Event TextChanged berjalan ketika isi TextBox berubah.
Pastikan LblHasil benar-benar ada di Form.

11. MENGUBAH TEKS LABEL LANGSUNG

LblHasil.Text = "Data berhasil ditampilkan"

12. MENGATUR PROPERTI DASAR LEWAT KODE
------------------------------------------------------------
' Mengubah teks yang terlihat pada Form.
Me.Text = "Aplikasi Data Mahasiswa"

' Mengubah teks pada tombol.
BtnTampilkan.Text = "Tampilkan Data"

' Mengubah teks pada Label.
LblHasil.Text = "Masukkan nama"

' Mengosongkan TextBox.
TxtNama.Clear()
------------------------------------------------------------
Properti juga bisa diatur melalui jendela Properties di Visual
Studio, tanpa menulis kode.

14. CARA CEPAT MEMILIH KODE SAAT UJIAN
------------------------------------------------------------
Soal meminta menampilkan pesan       -> MessageBox.Show(...)
Soal meminta mengambil input         -> NamaTextBox.Text
Soal meminta menampilkan ke Label    -> NamaLabel.Text = "..."
Soal meminta menggabungkan teks      -> gunakan &
Soal meminta membuat baris baru      -> gunakan vbCrLf
Soal meminta menghapus input         -> NamaTextBox.Clear()
Soal meminta menutup Form            -> Me.Close()
Soal meminta aksi saat tombol diklik -> event Click
Soal meminta aksi saat teks berubah  -> event TextChanged
